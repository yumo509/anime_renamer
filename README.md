# 动漫批量重命名工具
# anime_renamer

> 适配飞牛NAS / Plex / Emby / Jellyfin 刮削标准

一个智能的动漫资源批量重命名工具，自动从 TMDB / Bangumi 查询官方中文名，按媒体服务器刮削标准整理文件。

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux-lightgrey.svg)

## 📦 快速开始

```powershell
# 1. 安装依赖
pip install requests

# 2. 预览模式（先看效果，不实际修改文件）
python anime_renamer_v3.5.0.py Y:\backups\downloads --test

# 3. 交互式执行
python anime_renamer_v3.5.0.py
```

## ✨ 功能特点

- 🌐 **双源搜索**：TMDB（默认优先，Plex/Emby/Jellyfin 标准源）+ Bangumi（国内动漫数据库）
- 📁 **标准刮削格式**：`动漫名 (年份)/Season N/动漫名 SxxExx.ext`
- 🎬 **智能季数识别**：中文数字/罗马数字/阿拉伯数字/「x之章」
- 🔍 **Romaji 支持**：日语罗马音文件名自动匹配到正确中文名
- 📦 **智能归集**：API 搜不到时自动归集到罗马音/英文名文件夹
- 🔒 **安全预览**：先预览再执行，支持 `--test` 快速测试
- 🛡️ **冲突检测**：V2 版本文件自动加 `_2` 后缀，不覆盖
- ⚡ **零依赖**：仅需 `requests`，Windows/Linux 通用
- 🌍 **跨语言过滤**：防止英文搜索词被匹配到完全无关的中文结果
- 📜 **完整版权声明**：运行时显示版权和免责声明
